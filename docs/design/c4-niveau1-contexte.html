LocalAdvisor — C4 niveau 1 : Contexte

Qui utilise LocalAdvisor, et de quels systèmes externes dépend-il ? (un seul système, aucun dépendant externe à ce jour)

Acteurs

  • • Visiteur : accès public en lecture
  • • Utilisateur inscrit (USER) : écritures authentifiées
  • • Administrateur (ADMIN) : rôle présent en base, aucune règle d'accès
  • • Admin hérite de User dans le modèle d'acteurs

Périmètre du système

  • • SPA Vue 3 + API REST Spring Boot
  • • PostgreSQL 16 (conteneur)
  • • Authentification JWT stateless
  • • Aucun système externe requis aujourd'hui

Constats d'audit

  • • Notifications : README uniquement, non implémenté
  • • Carte interactive : non implémentée
  • • Suggestion de catégorie : modale sans endpoint
  • • Modération ADMIN : non implémentée
