LocalAdvisor — C4 niveau 2 : Conteneurs

Les unités déployables : une SPA, une API REST et une base de données, orchestrées par Docker Compose.

Conteneurs

  • • SPA Vue 3 servie par nginx (:4173)
  • • API REST Spring Boot (:8080)
  • • PostgreSQL 16 (:5432, volume dbdata)
  • • Orchestration : docker compose

Flux et sécurité

  • • HTTPS navigateur → SPA
  • • SPA → API en JSON, via nginx `/api`
  • • Écritures : `Authorization: Bearer <JWT>`
  • • GET publics : places, categories, reviews, images

Décisions et limites

  • • Monolithe Spring Boot assumé (pas de microservices)
  • • Ni cache, ni file de messages (volume faible)
  • • Images : URL en base, pas de stockage objet
  • • `ddl-auto=update`, migrations à introduire
